## Snowdrift 1.2.1

- **Бабочек и светлячков теперь можно выключить**: меню → «Время года» → «Бабочки и светлячки». Время года при этом не меняется: лепестки, пух и листья продолжают падать.

### Времена года 🌸☀️🍂❄️ (с версии 1.2.0)
- **Весна** — лепестки сакуры, цветущая сакура в углу, бабочки.
- **Лето** — пух одуванчиков и подсолнухи, вечером светлячки.
- **Осень** — листопад, кучки листьев на окнах, тыквы со свечкой.
- **Зима** — снег, снеговики, ёлка, гирлянда.
- Сезон меняется сам по календарю или выбирается в меню «Время года». ⌃⌥X / Ctrl+Alt+X убирает всех снеговиков.

### Обновление
Если у вас 1.1.x или новее, Snowdrift обновится сам, или нажмите «⬆ Обновить Snowdrift» в меню. С 1.0.0 или для новой установки используйте одну команду:

**Windows** (PowerShell):
```powershell
irm https://raw.githubusercontent.com/Ayanokoji771/snowdrift/main/install.ps1 | iex
```
**macOS** («Терминал»):
```bash
curl -fsSL https://raw.githubusercontent.com/Ayanokoji771/snowdrift/main/install.sh | bash
```

`SHA256SUMS.txt` — контрольные суммы архивов.
